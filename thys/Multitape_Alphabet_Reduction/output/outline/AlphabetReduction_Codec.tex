\begin{isamarkuptext}%
This theory opens the alphabet-reduction development.  The
  \isa{alphabet{\isacharunderscore}{\kern0pt}reduce} combinator takes a well-formed substrate
  machine over an arbitrary finite alphabet \isa{{\isacharprime}{\kern0pt}a} (with
  tape-alphabet cardinality \isa{{\isasymge}} 4) and produces a
  well-formed substrate machine over the fixed four-element alphabet
  \isa{sym{\isadigit{4}}}, preserving the accepted language, determinism, and
  tape count.

  This is the elementary determinism-preserving per-symbol multi-cell
  encoding.

  The development is layered: this first theory fixes the output
  alphabet \isa{sym{\isadigit{4}}} and the per-symbol binary codec; the
  simulator, its delta, and the headline theorems
  (\isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}wf}, \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}language},
  \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}time}, \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}det}) are
  built across the theories that follow.
  Throughout, \isa{b} abbreviates \isa{block{\isacharunderscore}{\kern0pt}width\ {\isasymGamma}} (the per-symbol cell width).%
\end{isamarkuptext}\isamarkuptrue%

\begin{isamarkuptext}%
The per-source-symbol block length: the number of \isa{sym{\isadigit{4}}}
  cells that encode one \isa{{\isasymGamma}}-symbol, and the slowdown factor of
  the reduction.  At least \isa{{\isadigit{1}}} (to avoid degenerate empty
  encodings even for trivial \isa{{\isasymGamma}}), and otherwise
  \isa{{\isasymlceil}log\isactrlsub {\isadigit{2}}\ {\isacharparenleft}{\kern0pt}card\ {\isasymGamma}{\isacharparenright}{\kern0pt}{\isasymrceil}}, the fewest binary digits that
  index all of \isa{{\isasymGamma}}.  Defined combinatorially via \isa{LEAST}
  on the predicate \isa{card\ {\isasymGamma}\ {\isasymle}\ {\isadigit{2}}\ {\isacharcircum}{\kern0pt}\ n}; existence of such an
  \isa{n} follows from \isa{card\ {\isasymGamma}\ {\isasymle}\ {\isadigit{2}}\ {\isacharcircum}{\kern0pt}\ card\ {\isasymGamma}}
  (HOL.Power.\isa{less{\isacharunderscore}{\kern0pt}exp}).

  \textbf{What is counted.}  The index space \isa{{\isacharbraceleft}{\kern0pt}{\isachardot}{\kern0pt}{\isachardot}{\kern0pt}{\isacharless}{\kern0pt}\ card\ {\isasymGamma}{\isacharbraceright}{\kern0pt}}
  covers \emph{every} symbol of \isa{{\isasymGamma}}: the blank at index
  \isa{{\isadigit{0}}} (the anchor \isa{gamma{\isacharunderscore}{\kern0pt}enum} relies on --- see below), and
  the left endmarker \isa{le} as an ordinary coded symbol, since
  \isa{valid{\isacharunderscore}{\kern0pt}mttm} permits a machine to write \isa{le} at any tape
  position (its only special handling is the single \isa{LE{\isadigit{4}}} cell at
  position \isa{{\isadigit{0}}}).  So \isa{block{\isacharunderscore}{\kern0pt}width} is genuinely the width of
  this uniform code, not a loose bound on a smaller one --- but it is not
  the \emph{coding} minimum.  Reserving index \isa{{\isadigit{0}}} for the
  blank (so an all-\isa{BLANK{\isadigit{4}}} block reads back through the same
  accumulator) puts it one digit above
  \isa{{\isasymlceil}log\isactrlsub {\isadigit{2}}\ {\isacharparenleft}{\kern0pt}card\ {\isasymGamma}\ {\isacharminus}{\kern0pt}\ {\isadigit{1}}{\isacharparenright}{\kern0pt}{\isasymrceil}}, the width for the
  \isa{card\ {\isasymGamma}\ {\isacharminus}{\kern0pt}\ {\isadigit{1}}} non-blank symbols; the two agree except just
  past a power of two.  Detecting the all-\isa{BLANK{\isadigit{4}}} block directly
  would recover that digit, and additionally giving \isa{le} its own
  marker block would reach \isa{{\isasymlceil}log\isactrlsub {\isadigit{2}}\ {\isacharparenleft}{\kern0pt}card\ {\isasymGamma}\ {\isacharminus}{\kern0pt}\ {\isadigit{2}}{\isacharparenright}{\kern0pt}{\isasymrceil}}
  --- but each costs a marker-detection branch in the read and write
  phases, so that constant-factor gain is deliberately not taken.%

\begin{isamarkuptext}%
Encoding a single \isa{{\isacharprime}{\kern0pt}a}-symbol as a fixed-length list of
  \isa{sym{\isadigit{4}}}-symbols, parameterised over the source alphabet
  \isa{{\isasymGamma}} (a finite set, passed explicitly as a value rather
  than through a type-class constraint, so the construction is uniform
  over all source alphabets).  The
  length \isa{b} is the slowdown factor; the encoding is
  injective on \isa{{\isasymGamma}}.  The two bit symbols \isa{BIT{\isadigit{0}}},
  \isa{BIT{\isadigit{1}}} carry the payload; \isa{LE{\isadigit{4}}} and \isa{BLANK{\isadigit{4}}}
  do not appear in any encoder image.  For \isa{x\ {\isasymnotin}\ {\isasymGamma}} the
  encoder produces a value that's structurally well-shaped (a
  \isa{b}-cell bit list) but semantically arbitrary —
  downstream proofs always operate on \isa{x\ {\isasymin}\ {\isasymGamma}}.%
