\begin{isamarkuptext}%
The alphabet-reduction combinator preserves determinism: if
  \isa{M} is deterministic then so is \isa{alphabet{\isacharunderscore}{\kern0pt}reduce\ M}.  The
  language, time, and well-formedness theorems assume only
  well-formedness, so they already cover nondeterministic \isa{M};
  the result below extends the reduction \emph{up} to deterministic
  machines, turning the determinism-agnostic construction into a
  determinism-preserving one.

  The argument is structural.  \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}delta\ M} is the
  union of the five phase builders \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}read},
  \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}compute}, \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}write},
  \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}advance}, \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}next}, intersected with
  side conditions.  Each builder is single-valued: among the five, only
  \isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}compute} consults \isa{M}'s own transition
  relation, so it is the sole place \isa{M}-determinism enters; the
  other four are single-valued by pure case analysis on the bit-counter,
  the tape index, and the read cell (\isa{ar{\isacharunderscore}{\kern0pt}delta{\isacharunderscore}{\kern0pt}next} additionally
  needs \isa{t\ {\isasymnoteq}\ r}, which \isa{valid{\isacharunderscore}{\kern0pt}mttm} supplies).  The five
  builders are keyed to disjoint source substep tags, so two transitions
  sharing a source land in the same builder; and intersection with the
  side conditions only shrinks the relation, so single-valuedness of the
  union transfers to \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}delta\ M} and hence to the
  reduced machine.

  Each per-builder lemma below splits the \emph{source} tuple into its
  arms with \isa{elim\ UnE} and closes every arm against the full target
  builder: with the source fixed the arm discriminants are pinned, so the
  target collapses to one matching arm.  The \isa{block{\isacharunderscore}{\kern0pt}width{\isacharunderscore}{\kern0pt}pos} fact
  (\isa{{\isadigit{1}}\ {\isasymle}\ b}) rules out the degenerate \isa{b\ {\isacharequal}{\kern0pt}\ {\isadigit{0}}}
  aliasing where the per-bit arm boundaries would coincide.
  Throughout, \isa{b} abbreviates \isa{block{\isacharunderscore}{\kern0pt}width\ {\isasymGamma}} (the per-symbol cell width).%

  relation enters \isa{alphabet{\isacharunderscore}{\kern0pt}reduce{\isacharunderscore}{\kern0pt}delta}: a single
  \isa{{\isasymdelta}{\isacharprime}{\kern0pt}}-tuple per \isa{M}-\isa{{\isasymdelta}}-tuple, matching the
  source-stage decoded symbol vector \isa{buf}.  Single-valuedness
  here is exactly \isa{M}-determinism transported through that match.%
\end{isamarkuptext}\isamarkuptrue%
